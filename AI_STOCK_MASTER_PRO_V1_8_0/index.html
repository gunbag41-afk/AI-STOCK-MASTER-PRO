🚀 실제 주가를 보기 위한 온라인 배포 안내

현재 HTML 파일을 직접 열었다면 실제 주가 자동 조회는 불가능합니다. ZIP 안의 서버를 온라인에 배포하고, 배포된 HTTPS 주소에서 접속해야 합니다.

  1. 통합 ZIP 파일을 압축 해제합니다.
  2. GitHub 저장소에 Dockerfile, server.py, index.html, render.yaml을 업로드합니다.
  3. Render에서 해당 저장소를 Web Service로 연결하여 배포합니다.
  4. Render가 발급한 HTTPS 주소를 휴대폰 Chrome에서 엽니다.
  5. 서버 연결 확인 → 실제 과거 주가 불러오기를 실행합니다.

서버 연결 성공은 외부 주가 수신 성공을 보장하지 않습니다. 외부 제공처 오류가 발생하면 안내 메시지를 확인하세요. 비공식 데이터 제공처를 사용하므로 상업적 이용 전 이용 약관을 확인해야 합니다.
